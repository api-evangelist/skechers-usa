# Skechers U.S.A. (skechers-usa)
Skechers U.S.A. is an American lifestyle and performance footwear company (Fortune 500) that designs, develops, and markets a diverse range of footwear for men, women, and children across 170+ countries. Skechers operates direct-to-consumer digital commerce through skechers.com and its mobile app, wholesale partnerships with global retailers, and over 4,700 owned and franchised retail stores worldwide.

## APIs

### Skechers E-Commerce API
Skechers operates a direct-to-consumer digital commerce platform at skechers.com integrating product catalog management, inventory, order management, shipping, and returns with e-commerce infrastructure providers.

**Human URL:** [https://www.skechers.com](https://www.skechers.com)

### Skechers Plus Loyalty API
The Skechers Plus loyalty program enables customers to earn and redeem points across all purchase channels — online, in-store, and mobile — through a unified customer profile and rewards tracking system.

**Human URL:** [https://www.skechers.com/loyalty](https://www.skechers.com/loyalty)

#### Tags:
 - Customer Experience, Loyalty, Points, Retail

---

### Skechers Store Locator API
Geographic search for Skechers retail locations across 4,700+ company-owned, franchise, and licensed stores in 170+ countries, integrated into the website, mobile app, and third-party mapping services.

**Human URL:** [https://www.skechers.com/stores](https://www.skechers.com/stores)

#### Tags:
 - Geolocation, Retail, Store Locator
